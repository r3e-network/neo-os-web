## 添加酷炫交互动效（第六轮）

**用户要求**: 想要更多酷炫的交互和自动动效

**完成内容**:

2. 创建 `apps/shared/components-react/useHomeAnimations.ts` — 动效 Hook 库

**7 种动效清单**:
| 动效 | 技术 | 触发时机 |
|------|------|---------|
| Hero 区域入场 stagger | CSS `animation-delay` 阶梯 (0/80/160/240/320ms)，fade-up + scale-in | 页面加载时 |
| Hero 图标浮动 | CSS `@keyframes n3h-float` (3s infinite) | 入场后持续 |
| Badge 流光 | CSS `@keyframes n3h-shimmer` (2.5s infinite)，白色半透明光带扫过 | 持续 |
| 统计数字计数 | `useBatchCountUp` (requestAnimationFrame + easeOutExpo) | 滚动入视口时 |
| 功能卡片 3D tilt | `useCardTilt` (mouse move → perspective rotateX/Y) | 鼠标悬停时 |
| 排行榜 hover 展开 | CSS hover: translateX(4px) + rank/avatar scale(1.15) | 鼠标悬停时 |
| 按钮涟漪 | `useRipple` (click coordinate → expanding circle) | 点击时 |
| #1 排名光环 | CSS `@keyframes n3h-rank-glow` (2.5s infinite box-shadow pulse) | 持续 |
| 滚动揭示 | `useScrollReveal` (IntersectionObserver → fade-up + translateY) | 元素进入视口 |

3. 类型检查通过：MiniAppHomeShell 和 useHomeAnimations 均 0 errors

**技术约束**: 所有动效时长 ≤ 600ms（涟漪）/ ≤ 550ms（淡入）/ ≤ 3s（浮动循环），全部使用 ease-out-expo 缓动，无弹跳/弹簧/脉冲（除 loading dot）
