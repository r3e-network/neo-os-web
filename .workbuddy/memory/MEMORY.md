# Neo MiniApps Platform — Workspace Memory

## 项目背景
Neo N3 区块链小程序平台，包含约 75 个小程序应用，技术栈：Next.js 15 + React 18 + Tailwind + SCSS

## 设计系统

品牌色: #16C784 (Neo Green)
目标用户: 终端消费者 (游戏/DeFi/NFT用户)
设计风格: 温暖明亮极简主义
