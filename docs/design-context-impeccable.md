## Design Context

### Users
- **终端消费者**: Web3 用户（游戏玩家、DeFi 交易者、NFT 收藏家），在 Neo N3 区块链上使用去中心化小程序
- **开发者**: 构建和部署小程序到 Neo MiniApps 平台
- **平台管理员**: 通过管理控制台管理小程序、用户、合约和运营数据

### Brand Personality
- **信任感**: 区块链原生，安全可靠，数据透明
- **活力感**: 趣味、可玩、有惊喜 — 不是冰冷的金融工具
- **未来感**: 简洁现代，但不冷漠 — 温暖而有温度的科技品牌

**3 词人格**: Trusted · Playful · Bright

### Aesthetic Direction
- **视觉基调**: 温暖明亮的极简主义 — 干净画布配上丰富的品牌点缀
- **参考**: Phantom Wallet 的沉浸式首页、Rainbow Wallet 的趣味图标设计、Apple App Store 的编辑推荐布局
- **避免**: 伪暗黑风格（没有深色默认）、过度的毛玻璃、通用 AI 美学（蓝紫渐变+霓虹）

### Design Principles
1. **品牌优先** — Neo Green #16C784 在不同场景中自然渗透，不只是按钮色
2. **沉浸但不压迫** — 白底为主，通过分类色彩营造氛围层次，而非大面积深色
3. **动效辅助理解** — 过渡自然流畅，不打断用户心流
4. **引导式设计** — 空状态、错误提示都有教育意义，帮助 Web3 新手理解链上操作
5. **差异化表达** — 每个小程序类别有独特视觉识别，拒绝千篇一律的卡片
