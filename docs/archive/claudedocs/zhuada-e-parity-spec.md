## 1. 原版核心体验（基准）

1. **核心循环**：3D 物理堆（围栏/盒中一大堆可爱物件，互相碰撞、有遮挡纵深）→ 点击抓取 → 飞入底部**7 格卡槽** → **3 个相同自动消除**（pop）→ 堆清空 = 过关；**卡槽满且无法消除 = 失败**。
2. **压力来源 = 卡槽逼近满 + 堆的可解性**，原版**无硬倒计时**（与我们 v2.3 的 timer-驱动不同 — 需改）。
3. **道具（原版三件套）**：**移出**（把卡槽前 3 个移到场边暂存位）、**撤回**（撤销上一次抓取，物件回堆）、**洗牌**（重排堆）。攻略另提"提示"类辅助。
4. **摇一摇**：晃动手机让堆重新落位、露出被埋物件（浏览器端用"晃一晃"按钮施加物理冲量，同等体验）。
5. **关卡结构**：第 1 关教学（轻松保底胜）→ 第 2 关起难度陡增；**6 个场景 × 每场景 2 关**；通过场景第 2 关获得**场景限定大鹅**（收集钩子）并进入**全国排行榜**。
6. **感受**：俯视相机看进围栏、物件呆萌、消除干脆、大鹅吉祥物庆祝、界面音效精良。
