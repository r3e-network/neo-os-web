## ⭐ SINGLE HIGHEST-LEVERAGE CHANGE

**Collapse the 3 contract-address sources of truth to 1, and add a drift guard that fails CI on stores (2) and (3).**

This is the structural root cause behind ~10 of the confirmed findings (host stats wrong, activity feed empty, cron targeting dead contracts, host detail-page invoke misrouting funds, false-green coverage audit). The existing guard (`deploy/scripts/lib/miniapp_contract_registry.test.mjs`) only validates store (1). Stores (2) `runtime.modules[].networks[].contract_hash` and (3) `contract-queries.ts` hardcoded map have silently drifted. Fix the guard *first* — it forces and verifies every contract-address fix in Waves A/B/C and prevents the entire bug class from recurring.

**Critical implementation note from the verdicts:** the drift lives in the **served `public/miniapp-definitions/*.json`** (both `manifest.contracts` and `manifest.runtime` carry the old kernel `0xa7840a8d`/`0x740671b1`), NOT only in `apps/*/neo-manifest.json`. Any fix that edits only `apps/*` will leave 3 of 4 apps broken. This must regenerate/repoint the served definitions.
