# 时间胶囊

一个以胶囊为主角的 Neo N3 小程序：把本地消息哈希封存在可退还押金的时间锁中。

## 生产流程

1. 写标题和消息。完整消息只保存在当前浏览器，链上仅提交 SHA-256 摘要。
2. 选择 1–3650 天锁定期；类别、精确天数和公开性放在渐进设置中。
3. 预付 0.2 GAS 可退还押金并调用 `bury`。只有精确 `Buried` 事件与 `getCapsule` 回读一致后才显示成功。
4. 倒计时结束后，所有者调用 `reveal`；已部署合约会原子退回押金，前端同样要求精确事件与回读。
5. 其他钱包可通过 `miniapp-timecapsule:fish:<id>` 备注向公开且未揭示的胶囊一次性打赏 0.05 GAS；已部署合约会在同一笔交易中直接转给所有者。

广播不等于成功。任何钱包写入前，应用都会验证恢复存储能够完整写入并回读。未确认交易会持久化精确网络、合约、钱包、意图和交易 ID，阻止重复提交，并支持刷新后继续检查。若广播后恢复存储异常，应用会在当前会话保留交易 ID，并明确提示用户不要再次提交。RPC 失败会显示“数据不可用”，不会伪装成 0 余额或空胶囊库。

产品界面以胶囊为主角：明亮的封存舱资源、本地信件和唯一主操作“封存胶囊”占据主舞台；精确时长、类别、可见性、胶囊历史、公开打赏和押金恢复都收进详情抽屉。封存动画只跟随真实交易生命周期，不再使用计时器制造预览成功。

## 当前链上边界

| 属性 | 值 |
|---|---|
| 应用 ID | `miniapp-time-capsule` |
| 分类 | 社交 |
| 版本 | 1.1.0 |
| 主网合约 | `0x3e88058ef32c4d8d17eb1a2188d6d5e329c94f8a` |
| 测试网合约 | `0x3e88058ef32c4d8d17eb1a2188d6d5e329c94f8a` |
| 状态端点 | `https://api.n3index.dev/{mainnet,testnet}` |

已部署 ABI 支持 `bury`、`reveal`、`withdraw` 与胶囊/余额读取。打赏由 `onNEP17Payment` 处理并发出 `Fished`。已部署版本会直接转账给所有者，不包含本地新版合约构建中的 `fishRevenueOf` / `withdrawFishRevenue` 账本接口，因此前端不会展示不可用的“领取打赏”按钮。

该业务无需预言机：时间锁使用 Neo 运行时，退款和打赏依赖 Neo N3 原子执行。

当前只完成线上只读验证；前端证据、资源来源与资金写入边界分别见 `PRODUCTION_STATUS.md`、`ASSET_PROVENANCE.md` 和 `TESTNET_STATUS.md`。
