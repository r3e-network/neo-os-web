# Sheep Solitaire asset provenance

All visible game art in `public/art/` was generated specifically for this
project during the July 2026 miniapp visual refresh. The app does not copy art
from `IcedSoul/minigame-everyday`; that repository is used only as a gameplay
mechanism reference because its asset licensing is not sufficiently explicit
for direct reuse.

The original coordinated tile, mascot, badge, tray, and meadow source sheet is:

The production mascot was regenerated from the project sprite to remove crop
artifacts and provide a clean warm-cream game background:

`/Users/jinghuiliao/.codex/generated_images/019f4fb3-853e-7360-af62-ecb43be42848/exec-41468b3d-2ea0-4fba-9b7a-9b5343438d7e.png`

The UI uses Lucide React for interface-only icons. Gameplay tiles, mascot,
difficulty badges, meadow table, and slot tray are raster game resources rather
than emoji, CSS drawings, or copied third-party sprites.
