# 永恒相册

永恒相册是一款按已连接 Neo 钱包地址隔离的小型本机相册。钱包仅作为本地相册身份：保存、查看、解密和删除照片都不会产生交易或 GAS 费用。

## 产品模型

- 照片只保存在本设备此浏览器的 `localStorage` 中。
- 已连接的钱包地址用于选择独立的本地相册分区。
- 可选密码保护会保存 AES-256-GCM 密文；密码既不会持久化，也不会发送出去。
- 不使用合约、链读取、平台存储写入、云同步或恢复服务。
- 清除站点数据会删除本地相册，用户必须在其他位置备份原图。

## 使用流程

1. 选择最多五张 JPEG、PNG、WebP、AVIF 或 GIF 图片。
2. 查看真实图片预览和本地容量计。
3. 可选开启加密并再次确认密码。
4. 如有需要，连接钱包以选择本地相册分区。
5. 保存到本设备；只有写入后回读确认成功才会显示成功提示。
6. 打开图片、在本地解锁加密回忆，或删除项目释放空间。

## 容量与恢复

- 单张照片 data URL：最多 768 KiB。
- 支持的导入会根据 JPEG、PNG、WebP、AVIF 或 GIF 的真实文件签名验证，而不是只信任文件名或 MIME 标签。
- 单次导入：最多五张，可选加密后总计不超过 2 MiB。
- 单钱包相册：本设备上最多保存 3 MiB 照片数据。
- 写入失败或存储空间不足时，已选照片会保留以便重试。
- 钱包切换会立即清除上一个钱包的画廊和敏感草稿状态。取消解锁或切换钱包也会让进行中的解密失效，较晚返回的结果不会重新打开旧分区照片。
- 本地数据损坏会明确提示；可读取项目会被恢复，完全不可读时可仅重置当前钱包相册。

## 存储格式

为兼容旧数据，框架命名空间继续使用 `forever-album:`。每个钱包相册以带版本的封装格式存储在 `forever-album:photos:<address>`；读取器同时兼容早期的裸数组本地格式。
