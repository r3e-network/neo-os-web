# Last Survivor（最后生还者）

Last Survivor 是一款明亮的 Phaser 3「最后席位」对决。当前生产入口中，本地对手会以不可预测的节奏抢占领先。玩家要在更安全的大包装填与得分更高的小包装填之间取舍，夺回最后席位，并在倒计时归零时仍然守住它。

## 玩家流程

1. 进入免费的 Phaser 竞技场；不会请求钱包或 GAS。
2. 装填一组钥匙，占领空缺的最后席位。大包装填增加更多时间，小包装填保留更高得分空间。
3. 盯住实时领先提示。本地对手会抢走席位，并为倒计时增加少量时间。
4. 在接近归零时夺回席位可获得极限加分。玩家已领先时控制会锁定，避免刷分。
5. 归零时若仍领先，即把压力分写入尽力而为的离线榜单；若被淘汰，可立即重开。

GameFi 合约路径已经实现，但当前前端版本不会公开展示。测试网合约已完成双钱包“购买 → 到期 → 结算 → 提取”验证；前端现已为每一笔钱包写入建立持久恢复记录，阻止重复提交，并要求精确事件与合约回读一致，不过此新版仍需重新跑一轮浏览器／钱包矩阵。运行时会独立拒绝新的付费轮次，同时为旧深链保留历史余额和结算恢复能力。

## 已验证的测试网合约规则

- 基础钥匙价格：`10_000_000` 基础单位（0.1 GAS）。
- 每把钥匙的价格增量：`10_000` 基础单位。
- 每把钥匙将有效倒计时延长 30 秒。
- 剩余时间最多 86,400 秒。
- 单笔最多购买 1,000 把钥匙。
- 任何人都可结算；结算采用拉取式余额，不会在 `settle` 内直接向赢家推送 GAS。
- 本游戏不依赖预言机或链下随机数。

### 公开 ABI

| 方法 | 类型 | 用途 |
| --- | --- | --- |
| `getCurrentRound()` / `getRound(id)` | 读取 | 轮次、奖池、钥匙总数、最后买家、结束时间和状态 |
| `currentKeyCost(count)` / `keyCost(total,count)` | 读取 | 权威等差价格报价 |
| `playerKeys(roundId,player)` | 读取 | 玩家在指定轮次的钥匙总数 |
| `creditOf(player)` | 读取 | 可复用充值或赢家余额 |
| `buyKeys(player,count)` | 写入 | 消耗余额、扩大奖池、成为最后买家并延长倒计时 |
| `settle()` | 写入 | 给赢家记账并开启下一轮 |
| `withdraw(account)` | 写入 | 提取全部可复用／赢家余额 |

## 开发

```bash
cd apps/last-survivor
npm test
npm run build
npm run dev
```

生产界面使用 React + Phaser 3。免费模式完全在本地运行，不会调用钱包、链上合约、预言机或奖励写入。前端验证结果见 [`PRODUCTION_STATUS.md`](./PRODUCTION_STATUS.md)，付费入口开放门槛见 [`TESTNET-STATUS.md`](./TESTNET-STATUS.md)，当前美术记录见 [`ASSET_PROVENANCE.md`](./ASSET_PROVENANCE.md)。
