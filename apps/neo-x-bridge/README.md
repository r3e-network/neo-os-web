# Neo X Bridge

Official Neo N3 ↔ Neo X bridge launcher.

## Scope

This miniapp does not implement custom bridge logic.

It provides:

- official bridge entry links
- official Neo X mainnet/testnet wallet network parameters
- official explorer and quick-start links

## Official Endpoints

- Mainnet bridge: `https://xbridge.neo.org/`
- Testnet bridge: `https://testnet.bridge.banelabs.org/`
- Official docs: `https://xdocs.ngd.network/bridge/quick-start-bridging-assets`

## Notes

- Bridge availability and supported assets are determined by the official bridge UI.
- The current official quick-start flow is the source of truth.
