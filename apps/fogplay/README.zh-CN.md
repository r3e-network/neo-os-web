# FogPlay（迷雾对决）— 预言机驱动的链上猜硬币

> 选正面还是反面，下注，等待链上回调完成结算。流程直接，结果可审计。

## 这是什么？

FogPlay 是一款基于 Neo N3 的链上猜硬币游戏。选择正面或反面，下注 GAS（0.05–100 GAS），由合约向 Morpheus Oracle 发起随机数请求，并在回调到达后完成结算。

FogPlay 的重点不只是速度，更是流程足够清楚。翻转、赢、输都有音效反馈，硬币翻转动画在短暂的结算窗口中营造悬念。简单的机制、真实的赌注、即时的反馈，让它非常适合高频短局体验。

每一次翻转都可证明公平。下注会先上链，随后由预言机回调提供随机结果，最终结果与收益都由合约记录和发出事件。

## 玩法说明

1. **连接** — 打开 FogPlay，连接钱包或社交账号登录。
2. **选择立场** — 点击正面或反面。
3. **设定赌注** — 输入 0.05 到 100 GAS 之间的金额。
4. **翻转！** — 点击翻转按钮，硬币伴随流畅动画旋转。
5. **快速结果** — 预言机回调到达后即可揭晓胜负。赢家获得 2 倍赌注（扣除平台费用），输家看到硬币落在错误的一面。
6. **再来一局** — 当前一局完成结算后即可继续下一局。

## 核心特性

- **直接预言机结算**：合约直接请求随机数，并在回调后上链结算。
- **可审计公平性**：每次翻转都绑定到具体的预言机请求，并在链上留下结果。
- **沉浸体验**：硬币翻转动画、翻转/赢/输音效、胜利全屏特效。
- **战绩追踪**：每局的总胜场、负场、游戏次数和赢得的 GAS 都有记录。
- **灵活赌注**：每次翻转可下注 0.05 到 100 GAS。
- **失败重试**：交易失败时提供重试按钮，不会丢失赌注。

## 技术架构

### 智能合约

| 组件         | 详情                                                       |
| ------------ | ---------------------------------------------------------- |
| **合约名称** | `MiniAppFogPlay`                                          |
| **开发语言** | C#（Neo N3 智能合约）                                      |
| **区块链**   | Neo N3                                                     |
| **赌注范围** | 0.05 – 100 GAS                                             |
| **结算流程** | `placeBet` → 预言机请求 → `onOracleResult` 回调 |

### 集成路径

- **Morpheus Oracle**：每次下注都会触发一次随机数回调。
- **链上结算**：下注状态、开奖结果和收益事件都由合约记录。
- **预付 GAS + Oracle 费信用**：用户先向小程序合约预付 GAS，回调合约还需要预付 Morpheus Oracle 请求费信用。

### 合约接口

| 方法                    | 类型 | 参数                                   | 说明                          |
| ----------------------- | ---- | -------------------------------------- | ----------------------------- |
| `placeBet`              | 操作 | `player`, `amount`, `choice` | 用户预付 GAS 后下注，并触发预言机随机数请求 |
| `onOracleResult`        | 操作 | `requestId`, `requestType`, `success`, `result`, `error` | 预言机回调并完成结算 |
| `getBet`                | 查询 | `betId`                                    | 获取特定投注详情 |
| `getPlayerDailyBet`     | 查询 | `player`                                   | 获取玩家当日下注总额 |
| `getPlayerBetCount`     | 查询 | `player`                                   | 获取玩家当前连续下注次数 |
