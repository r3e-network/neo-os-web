# NeoPay（流式支付）— 链上周期付款金库

> 创建周期性的 GAS 或 NEO 资金流。资金锁定在链上，按计划释放，受益人可在可领取时提取。

## 这是什么？

NeoPay 是一个流式支付协议，将可编程货币的能力带入日常场景。你可以为工资、订阅、会员费、津贴或金库释放建立一个支付流，让资金按预设节奏逐步释放。

可以把它理解为 Web3 版的可编程归属金库：资金锁定在智能合约中，按时释放，受益人随时可领。发送方保留取消权以回收未释放的资金，而受益人则可以确信已释放的资金不会被撤回。

> **当前状态**：`MiniAppNeoPay` 已部署到测试网和主网。2026-07-11 已通过只读 RPC 核验双网实时 ABI、暂停状态、总数量和最新资金流，详见 [NETWORK_STATUS.md](./NETWORK_STATUS.md)。

## 使用方法

1. **连接钱包** — 使用 Neo N3 钱包作为支付流创建者登录。
2. **设定受益人** — 输入支付接收方的 Neo N3 地址。
3. **选择资产** — 选择 GAS 或 NEO 作为支付资产。
4. **设计释放计划** — 设定总金额和周期（1–365 天），NeoPay 使用精确最小单位运算推导释放速率，不使用浮点数。小数 NEO 会保持为明确的无效输入，不会被静默截断成另一笔金额。
5. **添加说明** — 可选填写给收款人的简短备注。
6. **原子创建支付流** — 一次钱包确认同时完成注资与 `createStream`；任一脚本失败时整笔交易都会回滚。
7. **受益人领取** — 接收方随时可以访问 NeoPay、连接钱包，领取已释放的资金。
8. **取消（可选）** — 创建者可以随时取消支付流，回收未释放的资金。

## 核心特性

- **可编程支付**：设定总金额、释放速率和周期，支付自动执行。
- **双视角仪表盘**：创建者查看已设置的支付流，受益人查看收款中的支付流，同一界面两种视角。
- **多资产支持**：原生支持 GAS 和 NEO 两种资产的流式支付。
- **取消与回收**：创建者随时可以取消支付流，回收未释放的资金。
- **随时领取**：受益人可在任意时间领取已释放的资金，没有固定的领取窗口。
- **链上释放计划**：释放节奏和可领取金额完全由合约维护。
- **严格确认**：只有精确匹配应用事件并通过 `getStreamDetails` 回读，界面才显示成功。
- **交易恢复**：创建、领取、取消提交后，会绑定原钱包、网络和合约，直到确认成功或证明链上 `FAULT`。
- **可靠交易记录**：只有本地交易记录通过写入、回读、删除和删除回读后才会唤起钱包；清理失败时会继续保留准确的待确认操作。
- **稳定账户视图**：旧钱包的迟到读取结果会被丢弃，并重新加载当前连接钱包的数据。
- **写操作网络核验**：只读浏览可在网络探测短暂失败时继续，但创建、领取、取消和恢复必须等到钱包网络被明确识别后才能进行。
- **产品化工作台**：插画支付路线、金额、收款人与周期占据主位；备注、精确天数、说明和已验证支付流历史收进次级抽屉；超过产品读取上限时会明确标记为不完整视图。

## 技术架构

### 智能合约

| 组件         | 详情                   |
| ------------ | ---------------------- |

| **开发语言** | C#（Neo N3 智能合约）  |

### 当前边界

- **当前已上线**：直接钱包交易、链上流式账本、受益人领取、创建者取消。
- **确认边界**：交易广播不等于成功。必须匹配预期应用事件和权威资金流回读；未决广播会保留恢复入口。
- **操作边界**：创建、领取、取消、恢复和记录修复共用同一操作通道；预检期间钱包或网络变化会在广播前终止。
- **尚未上线**：AA 定时调度、NeoDID 身份校验、TEE 隐私处理。

### 合约接口

| 方法                    | 类型 | 参数                                                                                                | 说明                       |
| ----------------------- | ---- | --------------------------------------------------------------------------------------------------- | -------------------------- |
| `createStream`          | 操作 | `creator`, `beneficiary`, `asset`, `totalAmount`, `rateAmount`, `intervalSeconds`, `title`, `notes` | 与 NEP-17 转账在同一原子交易中创建资金流 |
| `claimStream`           | 操作 | `beneficiary`, `streamId`                                                                           | 领取已释放的资金           |
| `cancelStream`          | 操作 | `creator`, `streamId`                                                                               | 取消支付流，回收未释放资金 |
| `getStreamDetails`      | 查询 | `streamId`                                                                                          | 获取支付流参数和状态       |
| `getUserStreams`        | 查询 | `user`, `offset`, `limit`                                                                           | 获取用户创建的支付流       |
| `getBeneficiaryStreams` | 查询 | `beneficiary`, `offset`, `limit`                                                                    | 获取用户作为受益人的支付流 |
