# NeoPay（流式支付）— 链上周期付款金库

> 创建周期性的 GAS 或 NEO 资金流。资金锁定在链上，按计划释放，受益人可在可领取时提取。

## 这是什么？

NeoPay 是一个流式支付协议，将可编程货币的能力带入日常场景。你可以为工资、订阅、会员费、津贴或金库释放建立一个支付流，让资金按预设节奏逐步释放。

可以把它理解为 Web3 版的可编程归属金库：资金锁定在智能合约中，按时释放，受益人随时可领。发送方保留取消权以回收未释放的资金，而受益人则可以确信已释放的资金不会被撤回。

>
> **共享模式示例定义**：仓库已新增 `platform/host-app/public/miniapp-definitions/neo-pay.shared.json`，用来描述基于 `recipe.payment_streams.v1`、`module.funding_vault` 与 `module.stream_vesting` 的 NeoPay shared-mode 示例，不会替换当前生效的 `neo-pay.json`。

## 使用方法

1. **连接钱包** — 使用 Neo N3 钱包作为支付流创建者登录。
2. **设定受益人** — 输入支付接收方的 Neo N3 地址。
3. **选择资产** — 选择 GAS 或 NEO 作为支付资产。
4. **配置支付流** — 设定总金额、每期释放金额和释放周期（1–365 天）。
5. **添加备注** — 可选添加标题和备注用于记录。
6. **创建支付流** — 确认交易。总金额立即锁定在智能合约中。
7. **受益人领取** — 接收方随时可以访问 NeoPay、连接钱包，领取已释放的资金。
8. **取消（可选）** — 创建者可以随时取消支付流，回收未释放的资金。

## 核心特性

- **可编程支付**：设定总金额、释放速率和周期，支付自动执行。
- **双视角仪表盘**：创建者查看已设置的支付流，受益人查看收款中的支付流，同一界面两种视角。
- **多资产支持**：原生支持 GAS 和 NEO 两种资产的流式支付。
- **取消与回收**：创建者随时可以取消支付流，回收未释放的资金。
- **随时领取**：受益人可在任意时间领取已释放的资金，没有固定的领取窗口。
- **链上释放计划**：释放节奏和可领取金额完全由合约维护。

## 技术架构

### 智能合约

| 组件         | 详情                   |
| ------------ | ---------------------- |
| **合约名称** | `MiniAppNeoPay`   |
| **开发语言** | C#（Neo N3 智能合约）  |

### 当前边界

- **当前已上线**：直接钱包交易、链上流式账本、受益人领取、创建者取消。
- **尚未上线**：AA 定时调度、NeoDID 身份校验、TEE 隐私处理。

### 合约接口

| 方法                    | 类型 | 参数                                                                                                | 说明                       |
| ----------------------- | ---- | --------------------------------------------------------------------------------------------------- | -------------------------- |
| `createStream`          | 操作 | `creator`, `beneficiary`, `asset`, `totalAmount`, `rateAmount`, `intervalSeconds`, `title`, `notes` | 先向合约预存资产，再创建新的支付流 |
| `claimStream`           | 操作 | `beneficiary`, `streamId`                                                                           | 领取已释放的资金           |
| `cancelStream`          | 操作 | `creator`, `streamId`                                                                               | 取消支付流，回收未释放资金 |
| `getStreamDetails`      | 查询 | `streamId`                                                                                          | 获取支付流参数和状态       |
| `getUserStreams`        | 查询 | `user`, `offset`, `limit`                                                                           | 获取用户创建的支付流       |
| `getBeneficiaryStreams` | 查询 | `beneficiary`, `offset`, `limit`                                                                    | 获取用户作为受益人的支付流 |
