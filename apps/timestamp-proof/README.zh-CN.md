# Timestamp Proof 时间戳证明

`Timestamp Proof` 是一个本地 SHA-256 证明记录工具，并支持可选的 Neo N3 上链锚定。

## 当前行为

- 在浏览器本地计算内容的 `SHA-256` 哈希
- 将证明记录保存在当前设备的浏览器本地存储中
- 为每条证明生成本地 proof id，方便之后查询
- 支持通过 proof id、摘要或原文重新验证已保存证明
- 在连接钱包后，可以用真实的 0 GAS 自转账把已保存摘要锚定到 Neo N3

## 隐私与可信边界

- 原始内容保留在用户设备上
- 本地证明是私密且免费的
- 上链锚定只会在公开交易数据中写入 `timestamp-proof:<摘要>`
- 已锚定证明可通过交易 payload 和区块时间进行第三方核验
- 本地证明只存在于创建它的浏览器配置中，清理浏览器存储会删除记录

## 使用方式

1. 输入文本、文档哈希或简短证明备注。
2. 创建本地证明条目。
3. 通过 proof id、摘要或原文重新打开并验证证明。
4. 可选：连接钱包，将最新证明摘要锚定到链上，供第三方公开核验。

## 不做什么

- 不上传原始文档
- 不把原文内容写入链上
- 不把本地证明伪装成公开链上证据
- 核心本地证明流程不依赖 Oracle 或 AA

## 技术细节

- 类型：前端工具，可选钱包交易
- 哈希函数：`SHA-256`
- 本地存储：浏览器 localStorage
- 锚定方式：0 GAS 自转账，并在交易数据中携带 `timestamp-proof:<摘要>`

## 后续升级路径

如果未来需要专用时间戳合约，应先部署合约，再在同一个变更中切换前端和 manifest。不要在没有真实部署依据的情况下重新引入合成交易 id 或伪合约调用。
