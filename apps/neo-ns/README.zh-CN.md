# Neo 域名服务

Neo 域名服务是面向 Neo N3 官方 NameService 合约的生产级命名工作台。主流程是“搜索 → 确认可用性和准确 GAS 价格 → 注册”；持有域名的解析、续费与转让位于次级抽屉中。

## 产品逻辑

- 在 RPC 请求前按照合约规则校验小写域名首段。
- 无需连接钱包即可搜索名称和查看实时价格；只有执行链上写入时才请求钱包。
- 明确区分可注册、已持有和委员会保留名称。
- 从当前网络读取所有者、到期时间、TXT 地址记录和准确的 Fixed8 GAS 价格。
- 通过 `getnep11balances` 获取钱包持有的 NEP-11 域名，并严格读取每个域名的属性与解析记录。
- 遇到重复、畸形、超量或缺少属性名称的 token 行时拒绝发布含糊的部分持有列表。
- RPC 读取失败时保留上次确认的列表，不会把失败显示成“0 个域名”或“到期时间 0”。
- 注册前再次检查可用性与价格。
- 每次查询结果都绑定到准确输入，较慢的旧请求不会覆盖较新的结果。
- 续费前必须确认实时报价；转让前需要二次确认。
- 明确标记已过期域名，展示完整持有列表，并避免向相同地址重复提交解析交易。
- 每个写操作都必须由钱包明确确认当前网络；启动网络回退仅用于只读查询。
- 在向钱包发起交易请求前，先验证恢复凭据能够写入、读回并删除。
- 钱包广播后立即持久化交易凭据。只有 HALT、ABI 中对应的准确 NNS 事件以及链上回读全部一致时才显示成功。
- 未确认交易可在刷新后恢复，交易号可直接复制，并阻止重复提交。

## 操作确认标准

| 操作 | 确认证据 |
| --- | --- |
| 注册 | `Transfer(null-or-expired-owner, owner, 1, name)` + 所有者/到期时间回读 |
| 续费 | `Renew(name, oldExpiry, newExpiry)` + 新到期时间准确回读 |
| 设置地址目标 | HALT 应用日志 + 所有者/TXT 地址回读 |
| 转让 | `Transfer(owner, receiver, 1, name)` + 新所有者回读 |

记录类型 `16` 是官方 NNS `TXT` 记录。本小程序在其中保存已校验的 Neo N3 地址，与平台既有合约域名约定一致。
