# 拼拼豆工坊

拼拼豆工坊是一款生产级 Phaser 3 拼图小游戏。核心是一块 14×14、含 140 个有效孔位的手作拼豆板。玩家选择颜色与底板不符的连片拼豆，将整片放入同色空位，或暂存在 14 格托盘；拼对的豆会锁定。

## 完整玩法

- 基于种子的确定性关卡生成，并附带构造式可解证明。
- 棋盘与托盘移动坚持“整片成功或完全不动”，不会悄悄只移动一部分。
- 托盘按所选颜色保持 FIFO 顺序，支持五步撤回、暂停、超时、死局检测、重开确认与刷新安全恢复。
- Phaser 原生触控、鼠标和键盘输入，具有整片移动动画、减少动态适配、简洁读屏播报和共享程序化音效。
- 使用原创明亮工坊插画与树脂拼豆资源，前景面板保持清楚的文字和图像对比度。
- 完全本地游玩：不连接钱包、不调用合约、不发交易、不涉及代币、预言机或付费模式。

## 操作

- 点击错位的连片拼豆进行选择。
- 点击同色空孔区域，完整放入所选拼豆片。
- 点击“移入托盘”，或选中棋盘拼豆后直接点击托盘进行暂存。
- 选择托盘中的一种颜色，再点击同色空位。
- 键盘：方向键移动焦点，Enter/空格确认，Tab 切换棋盘/托盘，T 移入托盘，U 撤回，P 暂停，R 打开重开确认。
