# 螺丝工坊

螺丝工坊是一款面向 Neo MiniApps 平台的生产级 Phaser 3 益智游戏。它可以完整本地游玩：不需要、也不会宣传钱包、GAS、合约、预言机、TEE 或链上写入。

## 玩法规则

1. 点击露出的螺丝。被更高层木板盖住的螺丝必须等上层木板清空后才能拆。
2. 颜色匹配时，螺丝会飞入同色工具箱。每个工具箱收满三颗后，该通道切换到下一种颜色。
3. 暂时没有同色工具箱时，螺丝进入备选槽。
4. 五个备选槽都可以安全使用；**第六颗不匹配螺丝**才会导致失败。这里明确修正了参考实现中“满 5 即失败”的错误文案。
5. 清空所有木板、清空备选槽，并完成全部工具箱颜色队列即可通关。

## 操作与错误恢复

- 点击/轻触螺丝：拆卸并收纳。
- `Ctrl/Cmd + Z`：撤回，最多三次。
- `P` 或 `Space`：暂停/继续。
- `R`：按当前确定性种子重开。
- 新关卡：本局结束后生成新的本地种子。

关卡进度、紧凑操作轨迹与本地最佳成绩都会写入应用独立命名空间。刷新后恢复的未结束关卡一律以暂停状态打开，不会在加载界面背后继续运行。格式错误或语义不可能的持久化状态会被拒绝，并安全回退到干净关卡。

如果设备存储无法读取或写入，游戏仍会在内存中继续运行，并明确提示刷新恢复当前不可用，不会假装已经保存。练习排行榜更新失败也不会抹掉本地通关结果，并会单独给出友好提示。

玩家选中螺丝后，场景会立即提交动作，不再使用固定时长的“完成预演”。螺丝飞行动画、工具箱完成反馈、胜负界面与输入解锁，都只会在纯逻辑引擎发布了更高的权威 revision 和精确动作结果后启动。

## 确定性可解

每个关卡分三阶段构造。每阶段有四种互不相同的活动颜色，同一工具箱通道在相邻阶段不会保持同色。下层螺丝显式记录上层遮挡木板，同时关卡携带可重放的 `solutionOrder`。单元测试每次都会重放 2,000 个确定性种子。

恢复时不会只检查 JSON 结构，而是从干净关卡重新播放紧凑操作轨迹，再对比已拆螺丝、工具箱队列、备选槽顺序、步数与终局状态。即使格式正确，只要状态在规则上不可能，也会安全拒绝。

## GameFi 边界

游客/本地模式完整开放。`supportsGameFi` 为 false；发布清单中没有合约、权限、交易能力、预言机、AA 或 TEE 声明；运行时动作也不会调用钱包或链服务。只有在真实合约、已注资奖池、权威证明路径、错误恢复和测试网端到端结算全部独立验证后，才可以考虑开放奖励通道。

## 构建与验证

在 `apps/screw-sort` 下执行：

```bash
../../node_modules/.bin/tsc --noEmit -p tsconfig.json
../../node_modules/.bin/eslint src test vite.config.ts vitest.config.ts
../../node_modules/.bin/vitest run --config vitest.config.ts
npm run build
```

在仓库根目录执行共享迁移验收：

```bash
cd apps/shared
npx vitest run test/minigame-everyday-migrations.production.test.ts
```

手工测试：

```bash
npm run dev -- --port 5238
```

需要在 390×844 与短屏手机尺寸验证：四个工具箱、五格备选槽、48×52 逻辑像素触控区、正确板层遮挡、撤回/暂停/重开、第六颗不匹配螺丝失败、通关/新关卡、本地刷新恢复、声音开关、减少动态效果以及浏览器零错误。
