# 红包 — 链上红包，一键裂变

> 发红包、分享链接或口令、好友通过小程序领取。Neo N3 上的社交赠礼工具。

## 这是什么？

红包将华人世界最经典的社交传统搬上了区块链。存入 GAS 创建红包，生成分享链接或口令，好友即可通过小程序领取自己的份额。

这是 Web3 版的社交赠礼。发送者将 GAS 存入智能合约，选择均分或拼手气模式，然后通过任何社交平台分享链接或口令。领取者打开小程序、连接钱包并领取自己的份额。

红包的特别之处在于创建、领取和剩余额度都直接记录在链上。拼手气模式依然保留社交张力，但当前版本严格以已经部署的合约能力为准。

## 使用方法

1. **创建红包** — 连接钱包，输入 GAS 总金额和红包数量，添加自定义祝福语。
2. **选择分配方式** — 均分（每人相同金额）或拼手气（随机金额，手气最佳者额外获得 5% 奖励）。
3. **设置领取条件** — 可选择要求领取者持有一定数量的 NEO，或持有满一定天数。
4. **分享** — 获取专属链接或二维码，通过微信、Telegram、Twitter 等任意平台分享。
5. **好友领取** — 领取者打开链接，在小程序里连接钱包后领取自己的份额。
6. **过期退回** — 未领取的红包在过期后（默认 24 小时）自动退回给发送者。

## 核心特性

- **可分享领取**：生成链接或口令，让领取流程适合社交传播。
- **拼手气模式**：支持均分和随机金额两种发放方式。
- **链上可追踪**：红包状态、领取记录和剩余额度都可链上查询。
- **领取门槛**：可选要求领取者持有 NEO（最低持有量和/或持有天数）。
- **过期自动退回**：未领取的红包自动退还给发送者。
- **文化气息**：自定义祝福语、主题化界面、庆祝动画。

## 技术架构

### 智能合约

| 组件             | 详情                  |
| ---------------- | --------------------- |
| **合约名称**     | `MiniAppRedEnvelope`  |
| **开发语言**     | C#（Neo N3 智能合约） |
| **区块链**       | Neo N3                |
| **最低总额**     | 0.1 GAS               |
| **最大红包数**   | 每个信封 100 个       |
| **最低单个金额** | 0.01 GAS              |

### 服务层技术

- **基于合约的分配逻辑**：当前版本依赖合约状态和链上记录，而不是外部 AA / TEE / NeoDID 服务。

### 合约接口

| 方法                 | 类型 | 参数                                                         | 说明                   |
| -------------------- | ---- | ------------------------------------------------------------ | ---------------------- |
| `CreateEnvelope`     | 操作 | `creator`, `amount`, `count`, `expiry`, `minNeo`, `holdDays` | 创建新红包             |
| `ClaimEnvelope`      | 操作 | `claimer`, `envelopeId`                                      | 从红包中领取份额       |
| `RefundEnvelope`     | 操作 | `creator`, `envelopeId`                                      | 过期后退回未领取的红包 |
| `GetEnvelopeDetails` | 查询 | `envelopeId`                                                 | 获取红包详情和领取状态 |
