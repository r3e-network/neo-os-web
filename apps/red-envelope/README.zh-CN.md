# 红包 — 链上红包，一键裂变

> 发红包、分享链接、好友秒领——不用钱包，不用Gas。Web3 社交裂变的终极形态。

## 这是什么？

红包将华人世界最经典的社交传统搬上了区块链。存入 GAS 创建红包，生成分享链接，好友点击即可领取——即使他们从未用过加密钱包。账户抽象自动为新用户创建影子账户，TEE 确保拼手气红包的分配公平可验证。

这是 Web3 版的社交裂变。发送者将 GAS 存入智能合约，选择均分或拼手气模式，然后通过任何社交平台分享链接。领取者点击链接、社交账号登录、一键领取——Gas 费全免、无需配置钱包。这是一个不像 "用户引导" 的用户引导工具。

红包的特别之处在于 NeoDID 驱动的反女巫攻击层。经过验证的社交身份可以防止同一个人重复领取。TEE（可信执行环境）处理拼手气模式的随机分配计算，确保金额真正不可预测且可验证。

## 使用方法

1. **创建红包** — 连接钱包，输入 GAS 总金额和红包数量，添加自定义祝福语。
2. **选择分配方式** — 均分（每人相同金额）或拼手气（随机金额，手气最佳者额外获得 5% 奖励）。
3. **设置领取条件** — 可选择要求领取者持有一定数量的 NEO，或持有满一定天数。
4. **分享** — 获取专属链接或二维码，通过微信、Telegram、Twitter 等任意平台分享。
5. **好友领取** — 领取者打开链接，社交账号登录即可领取，无需钱包、无需 Gas。
6. **过期退回** — 未领取的红包在过期后（默认 24 小时）自动退回给发送者。

## 核心特性

- **零门槛领取**：领取者不需要任何钱包。AA 通过社交登录自动创建影子账户，Gas 费全免。
- **拼手气模式**：随机分配在 TEE 中计算，可证明公平。手气最佳者额外获得 5% 奖励。
- **防女巫攻击**：NeoDID 验证社交身份，防止一人重复领取。
- **领取门槛**：可选要求领取者持有 NEO（最低持有量和/或持有天数）。
- **过期自动退回**：未领取的红包自动退还给发送者。
- **文化气息**：自定义祝福语、主题化界面、庆祝动画。

## 技术架构

### 智能合约

| 组件             | 详情                  |
| ---------------- | --------------------- |
| **合约名称**     | `MiniAppRedEnvelope`  |
| **开发语言**     | C#（Neo N3 智能合约） |
| **区块链**       | Neo N3                |
| **最低总额**     | 0.1 GAS               |
| **最大红包数**   | 每个信封 100 个       |
| **最低单个金额** | 0.01 GAS              |

### 服务层技术

- **账户抽象（AA）**：通过社交登录自动为新用户创建账户，Gas 费全免。临时账户后续可升级为完整钱包。
- **TEE（可信执行环境）**：拼手气随机分配在 TEE 飞地中运行，确保金额不可预测且事后可验证。
- **NeoDID（去中心化身份）**：反女巫保护——领取需要经过验证的社交身份，防止重复领取。

### 合约接口

| 方法                 | 类型 | 参数                                                         | 说明                   |
| -------------------- | ---- | ------------------------------------------------------------ | ---------------------- |
| `CreateEnvelope`     | 操作 | `creator`, `amount`, `count`, `expiry`, `minNeo`, `holdDays` | 创建新红包             |
| `ClaimEnvelope`      | 操作 | `claimer`, `envelopeId`                                      | 从红包中领取份额       |
| `RefundEnvelope`     | 操作 | `creator`, `envelopeId`                                      | 过期后退回未领取的红包 |
| `GetEnvelopeDetails` | 查询 | `envelopeId`                                                 | 获取红包详情和领取状态 |
