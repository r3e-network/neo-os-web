# NeoDID 身份护照

NeoDID 身份护照是 DID 文档检查与本地核对包工具。它通过宿主平台解析 Morpheus NeoDID，展示返回文档与网络证据，并可让已连接的 Neo N3 钱包签署规范化核对文本；该精确文本会原样写入导出内容的 `proof.signedMessage`。

它**不会**签发凭证、证明 DID 所有权、验证用户填写的声明、验证钱包返回的签名、注册 DID 或广播交易。导出的摘要可以独立重算；核对包也会记录请求签名的精确文本，但宿主没有提供各钱包适配器的预映像约定，因此无法仅凭该核对包完成签名的密码学验证。除非钱包或提供方另行提供兼容的验证元数据，否则应把它视为不透明的钱包返回产物。

## 产品流程

1. 选择简短的核对场景；需要精确参数时再打开“核对详情”。
2. 解析 DID，并创建十分钟有效的本地核对包。
3. 核对 DID 文档、运行时元数据与注册表边界。
4. 可选附加钱包签名。应用会检查钱包地址、网络连续性以及钱包报告的实际签名账户（地址或脚本哈希形式），但仍把证明标记为“未验证”。
5. 复制包含 DID 解析快照、注册表观察结果、精确签名请求文本与验证限制的完整 JSON。

最新有效核对包只有在完成精确回读后才会被视为已保存在本地。如果存储不可用或静默忽略写入，内存中的 JSON 仍可复制，稍后可通过“重试本地恢复”保存同一核对包，无需再次解析或签名。五分钟内中断的解析读取可以恢复，且在写入替代恢复点前不会先删除旧恢复点；每次解析请求都有十秒超时。钱包弹窗绝不会自动重放，恢复后由用户自行决定是否重新签名。格式异常的签名编码会被拒绝，不会被补齐后当作有效产物。

## 网络事实

- 主网：仓库注册表快照声明的 NeoDIDRegistry 为 `0xb81f31ea81e279793b30411b82c2e82078b63105`。运行时，应用会通过只读 RPC 核验网络 Magic、精确合约哈希与 Manifest 名称。
- 测试网：仓库注册表快照没有 NeoDID 注册表部署。应用会明确显示这一限制，不会把解析器返回内容当成链上身份证明。
- 宿主解析器可以在未检查主体绑定时返回语法有效的文档，因此“文档已返回”绝不等于“身份已验证”。
