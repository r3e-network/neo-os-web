# SelfLoan（自我借贷）— 借的是未来，还的是时间

> 锁定 NEO，立即借出 GAS。质押收益自动还款，零清算风险，永远不会爆仓。

## 这是什么？

SelfLoan 是构建在 Neo N3 上的 Alchemix 风格自偿性借贷协议。锁定 NEO 作为抵押品，立即获得 GAS，然后让时间替你工作——锁定的 NEO 持续产生质押奖励（GAS），这些奖励自动偿还贷款。当贷款全部还清，NEO 自动解锁。

SelfLoan 最精妙之处在于它不可能被清算。传统 DeFi 借贷中，价格下跌可能导致抵押品被清算；而 SelfLoan 的债务用的正是抵押品产生的收益来偿还。不依赖价格预言机、没有追加保证金通知、没有连环清算。你只是在预支自己未来的收益。

三个 LTV（贷款价值比）档位让你自主选择风险偏好：保守型（20%）、均衡型（30%）、激进型（40%）。LTV 越高意味着前期拿到更多 GAS，但还款时间更长。借款时收取 0.5% 的平台费。Keeper 自动化持续监控健康系数，异常时发出预警。

## 使用方法

1. **连接钱包** — 连接持有 NEO 的 Neo N3 钱包。
2. **选择 LTV 档位** — 保守型（20%）、均衡型（30%）或激进型（40%），根据你对即时流动性和还款速度的偏好选择。
3. **输入抵押数量** — 指定锁定多少 NEO（必须为整数）。
4. **发起借贷** — 确认交易。GAS 立即到账，已扣除 0.5% 平台费。
5. **等待与观察** — 锁定的 NEO 产生质押收益，自动偿还贷款余额。在仪表盘上监控进度。
6. **管理与自动解锁** — 当前小程序 UI 主要提供借款和监控。合约本身支持手动还款，债务归零后抵押品会自动解锁返还。

当前真实借款路径在钱包层面是两步，但前端会自动串起来：

1. `NEO.transfer(..., "miniapp-self-loan:collateral")`
2. `createLoan(...)`

## 核心特性

- **零清算风险**：债务由同一抵押品的收益偿还。不依赖价格预言机，没有追加保证金通知。
- **即时 GAS 流动性**：凭锁定的 NEO 立即借出 GAS，无需等待质押收益累积。
- **三档 LTV**：保守型（20%）、均衡型（30%）、激进型（40%）——在即时流动性与还款速度之间自主选择。
- **自动还款**：贷款通过 NEO 质押收益自行偿还，设定即忘。
- **健康系数仪表盘**：实时查看贷款健康度、当前 LTV、抵押品利用率和还款进度。
- **Keeper 监控**：自动化健康系数监控，需要干预时发出预警。
- **低费率**：仅 0.5% 借款手续费，在创建贷款时一次性扣除。

## 技术架构

### 智能合约

| 组件         | 详情                                     |
| ------------ | ---------------------------------------- |
| **合约名称** | `MiniAppSelfLoan`                        |
| **开发语言** | C#（Neo N3 智能合约）                    |
| **区块链**   | Neo N3                                   |
| **LTV 档位** | 第 1 档：20%、第 2 档：30%、第 3 档：40% |
| **平台费**   | 0.5%（50 基点）借款手续费                |
| **最短期限** | 24 小时                                  |
| **抵押品**   | NEO（仅限整数）                          |
| **借出资产** | GAS                                      |

### 服务层技术

- **Keeper（自动化）**：持续监控所有活跃贷款的健康系数。健康系数接近阈值时触发预警，贷款被累积收益完全偿还后自动解锁抵押品。

### 合约接口

| 方法               | 类型 | 参数                                | 说明                                        |
| ------------------ | ---- | ----------------------------------- | ------------------------------------------- |
| `CreateLoan`       | 操作 | `borrower`, `collateral`, `ltvTier` | 锁定 NEO 并获得 GAS                         |
| `GetLoanDetails`   | 查询 | `loanId`                            | 获取贷款状态（抵押品、债务、活跃状态、LTV） |
| `GetPlatformStats` | 查询 | —                                   | 获取平台 LTV 档位、最短期限、费率           |
| `RepayDebt`        | 操作 | `loanId`, `payer`, `amount` | 使用直接预付 GAS 的合约层手动还款路径 |
