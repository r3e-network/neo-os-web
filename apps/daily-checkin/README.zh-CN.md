# 每日签到 — 坚持打卡，GAS 到手

> 每天签到、连续打卡、赚取 GAS。坚持就是收益，链上可查、铁证如山。

## 这是什么？

每日签到是在 Neo N3 上赚取 GAS 最简单的方式。每天打开应用、点一下签到按钮，就开始累积连续天数。连续 7 天签到获得 1 GAS，连续 14 天获得 2 GAS。断签一天？连续天数归零，重新开始挑战。

看似简单的机制背后蕴含着强大的驱动力。损失厌恶的心理——不想失去已经坚持了好几天的连续记录——让用户自然而然地每天回来。每次签到都记录在链上，你的连续天数可验证且不可篡改。随着连续天数增长，你还会获得逐级升级的 NFT 徽章，作为对 Neo 生态忠诚度的证明。

当前测试网版本保持了最直接的流程：连接 Neo N3 钱包、每天按 UTC 日签到一次、需要时再领取奖励。每一步都会上链，因此连续记录依然可验证且不可篡改。

## 使用方法

1. **打开应用** — 在 Neo MiniApps 平台启动每日签到。
2. **连接钱包** — 在签到或领取奖励前连接 Neo N3 钱包。
3. **点击签到** — 每个 UTC 日点击一次签到按钮，应用会显示距下次签到的倒计时。
4. **累积连续天数** — 每天签到不中断，当前连续天数和历史最高连续天数都会被追踪。
5. **赚取奖励** — 第 7 天获得 1 GAS，第 14 天获得 2 GAS。奖励累积，随时可领取。
6. **领取 GAS** — 点击领取按钮，将累积的 GAS 奖励提取到钱包。

## 核心特性

- **连续奖励**：基于连续签到天数的递增 GAS 奖励。
- **链上验证**：每次签到都记录在区块链上，连续天数可证明。
- **简单日常流程**：每个 UTC 日执行一次链上签到，规则清晰直接。
- **全局数据**：查看全平台签到用户数、签到总次数和已发放 GAS 总量。
- **签到历史**：完整的签到记录，包含连续天数和奖励金额。
- **UTC 日重置**：全球统一 UTC 00:00 重置，所有用户同一标准。

## 技术架构

### 智能合约

| 组件         | 详情                            |
| ------------ | ------------------------------- |
| **合约名称** | `MiniAppDailyCheckIn`           |
| **开发语言** | C#（Neo N3 智能合约）           |
| **区块链**   | Neo N3                          |
| **签到窗口** | 每 UTC 日一次（UTC 00:00 重置） |
| **签到费用** | 0.001 GAS                       |

### 当前集成边界

- **当前已上线**：直接钱包调用完成签到和奖励领取。
- **尚未上线**：AA Session Key 体验优化。

### 合约接口

| 方法               | 类型 | 参数     | 说明                                                                   |
| ------------------ | ---- | -------- | ---------------------------------------------------------------------- |
| `checkIn`          | 操作 | `player` | 执行每日签到                                                           |
| `claimRewards`     | 操作 | `player` | 领取累积的 GAS 奖励                                                    |
| `GetUserStats`     | 查询 | `player` | 返回连续天数、最高连续、上次签到日、未领取奖励、已领取总额、签到总次数 |
| `GetPlatformStats` | 查询 | —        | 返回总用户数、总签到次数、已发放 GAS 总量                              |
