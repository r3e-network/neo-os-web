# FogPlay（迷雾对决）— 链上瞬时硬币对决

> 选正面还是反面，下注，不到一秒出结果。没有等待、没有提交-揭示——纯粹的即时博弈，可证明公平。

## 这是什么？

FogPlay 是一款闪电般快速的链上硬币翻转游戏，体验感堪比原生手游。选择正面或反面，下注 GAS（0.05–100 GAS），瞬间得到结果——没有传统链上游戏那种漫长的提交-揭示延迟。核心秘诀在于 TEE（可信执行环境）：投注在安全飞地内结算，通过 VRF 种子生成结果，彻底跳过了大多数链上游戏所需的两阶段提交-揭示流程。

FogPlay 的独特之处不仅在于速度，更在于手感。账户抽象的 Session Key 让你可以连续翻转，无需每次都确认交易。翻转、赢、输都有音效反馈，硬币翻转动画在短暂的结算窗口中营造悬念。简单的机制、真实的赌注、即时的反馈——这是设计出来的沉浸感。

每一次翻转都可证明公平。VRF 种子在链上的 `initiateBet` 阶段生成，通过确定性哈希产生结果，并在 `settleBet` 中验证。任何人都可以重放哈希来确认结果未被篡改。

## 玩法说明

1. **连接** — 打开 FogPlay，连接钱包或社交账号登录。
2. **选择立场** — 点击正面或反面。
3. **设定赌注** — 输入 0.05 到 100 GAS 之间的金额。
4. **翻转！** — 点击翻转按钮，硬币伴随流畅动画旋转。
5. **即时结果** — 不到一秒，揭晓胜负。赢家获得 2 倍赌注（扣除平台费用），输家看到硬币落在错误的一面。
6. **再来一局** — Session Key 免去重复授权，随时继续。

## 核心特性

- **亚秒级结算**：TEE 消除提交-揭示延迟，结果几乎瞬间到达。
- **可证明公平**：VRF 种子 → SHA-256 哈希 → 确定性结果。每次翻转都可独立验证。
- **Session Key 连续玩**：AA Session Key 让你连续翻转，无需逐次签名。
- **沉浸体验**：硬币翻转动画、翻转/赢/输音效、胜利全屏特效。
- **战绩追踪**：每局的总胜场、负场、游戏次数和赢得的 GAS 都有记录。
- **灵活赌注**：每次翻转可下注 0.05 到 100 GAS。
- **失败重试**：交易失败时提供重试按钮，不会丢失赌注。

## 技术架构

### 智能合约

| 组件         | 详情                                                       |
| ------------ | ---------------------------------------------------------- |
| **合约名称** | `MiniAppCoinFlip`                                          |
| **开发语言** | C#（Neo N3 智能合约）                                      |
| **区块链**   | Neo N3                                                     |
| **赌注范围** | 0.05 – 100 GAS                                             |
| **结算流程** | `initiateBet` → VRF 种子 → SHA-256 哈希 → `settleBet` 验证 |

### 服务层技术

- **TEE（可信执行环境）**：投注在 TEE 飞地内结算。VRF 种子经哈希处理确定结果——无需提交-揭示。即时结算，密码学证明。
- **账户抽象（AA）**：Session Key 实现连续快速投注，每次翻转无需钱包弹窗。
- **VRF（可验证随机函数）**：链上可验证随机数生成每次翻转的种子。结果通过 SHA-256 确定性派生，每个结果都可独立验证。

### 合约接口

| 方法                    | 类型 | 参数                                   | 说明                          |
| ----------------------- | ---- | -------------------------------------- | ----------------------------- |
| `initiateBet`           | 操作 | `player`, `amount`, `choice`           | 下注——支付 GAS，生成 VRF 种子 |
| `settleBet`             | 操作 | `player`, `betId`, `won`, `scriptHash` | 结算投注——验证结果，分配奖金  |
| `getFlipScriptInfo`     | 查询 | —                                      | 获取翻转脚本哈希用于验证      |
| `GetBetDetails`         | 查询 | `betId`                                | 获取特定投注的详情            |
| `GetPlayerStatsDetails` | 查询 | `player`                               | 获取玩家胜负统计              |
