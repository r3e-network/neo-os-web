# NeoPay（流式支付）— 自动执行的链上薪资与订阅

> 设置薪资发放、订阅扣款或定期付款，链上自动执行。隐私保护、可编程、不可阻挡。

## 这是什么？

NeoPay 是一个流式支付协议，将可编程货币的能力带入日常场景。设置一个支付流——用于薪资发放、订阅服务、会员费或任何定期义务——资金按照设定的时间表自动从发送方流向接收方。一旦创建，支付流在链上去信任化执行，无需任何人工干预。

可以把它理解为 Web3 版的银行代扣或自动续费，但拥有区块链级别的保障：资金锁定在智能合约中，按时释放，受益人随时可领。发送方保留取消权以回收未释放的资金，而受益人则可以确信已释放的资金不会被撤回。

NeoPay 融合了三项前沿的 Neo 服务层技术。AA Hooks 实现自动化的定时支付执行，发送方无需在线。NeoDID 为薪资场景提供身份验证——雇主在发放工资前验证员工身份。TEE 在隐私环境中处理敏感的薪资细节，链上仅可见聚合后的转账金额。

> **注意**：NeoPay 目前处于开发阶段，智能合约尚未部署。

## 使用方法

1. **连接钱包** — 使用 Neo N3 钱包作为支付流创建者登录。
2. **设定受益人** — 输入支付接收方的 Neo N3 地址。
3. **选择资产** — 选择 GAS 或 NEO 作为支付资产。
4. **配置支付流** — 设定总金额、每期释放金额和释放周期（1–365 天）。
5. **添加备注** — 可选添加标题和备注用于记录。
6. **创建支付流** — 确认交易。总金额立即锁定在智能合约中。
7. **受益人领取** — 接收方随时可以访问 NeoPay、连接钱包，领取已释放的资金。
8. **取消（可选）** — 创建者可以随时取消支付流，回收未释放的资金。

## 核心特性

- **可编程支付**：设定总金额、释放速率和周期，支付自动执行。
- **双视角仪表盘**：创建者查看已设置的支付流，受益人查看收款中的支付流，同一界面两种视角。
- **多资产支持**：原生支持 GAS 和 NEO 两种资产的流式支付。
- **取消与回收**：创建者随时可以取消支付流，回收未释放的资金。
- **随时领取**：受益人可在任意时间领取已释放的资金，没有固定的领取窗口。
- **TEE 隐私保护**：敏感的薪资细节（个人工资金额）在 TEE 中处理——链上仅显示聚合总额。
- **身份验证**：NeoDID 确保受益人身份，满足合规性要求的薪资场景。
- **自动执行**：AA Hooks 自动触发定时支付——创建后发送方无需任何操作。

## 技术架构

### 智能合约

| 组件         | 详情                   |
| ------------ | ---------------------- |
| **合约名称** | `MiniAppStreamVault`   |
| **开发语言** | C#（Neo N3 智能合约）  |
| **区块链**   | Neo N3                 |
| **支持资产** | GAS、NEO               |
| **周期范围** | 1–365 天               |
| **当前状态** | 开发中（合约尚未部署） |

### 服务层技术

- **AA Hooks（账户抽象）**：自动化支付钩子在发送方不在线的情况下执行定时释放。支付流创建后，AA Hooks 处理后续的每一次定期执行。
- **NeoDID（去中心化身份）**：员工和订阅者身份验证。雇主可以要求在发放薪资前通过 NeoDID 验证。
- **TEE（可信执行环境）**：薪资细节（个人金额、接收人信息）在 TEE 飞地内处理。链上仅记录聚合后的转账金额，保护薪资隐私。

### 合约接口

| 方法                    | 类型 | 参数                                                                                                | 说明                       |
| ----------------------- | ---- | --------------------------------------------------------------------------------------------------- | -------------------------- |
| `CreateStream`          | 操作 | `creator`, `beneficiary`, `asset`, `totalAmount`, `rateAmount`, `intervalSeconds`, `title`, `notes` | 创建新的支付流             |
| `ClaimStream`           | 操作 | `beneficiary`, `streamId`                                                                           | 领取已释放的资金           |
| `CancelStream`          | 操作 | `creator`, `streamId`                                                                               | 取消支付流，回收未释放资金 |
| `GetStreamDetails`      | 查询 | `streamId`                                                                                          | 获取支付流参数和状态       |
| `getUserStreams`        | 查询 | `user`, `offset`, `limit`                                                                           | 获取用户创建的支付流       |
| `getBeneficiaryStreams` | 查询 | `beneficiary`, `offset`, `limit`                                                                    | 获取用户作为受益人的支付流 |
