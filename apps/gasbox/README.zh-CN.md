# GASBOX（GAS盲盒）— 转一转，赢大奖

> 投入 0.1 GAS，转动盲盒，赢取 NEO、稀有 NFT 或平台积分。每一次抽取都可验证公平。

## 这是什么？

GASBOX 是 Neo N3 上首个完全链上化的盲盒（扭蛋）体验。只需最低 0.1 GAS 即可抽奖，奖品涵盖 NEO 代币、稀有 NFT 和平台积分——全程由可验证随机函数（VRF）驱动，每一次抽取都可证明公平、不可篡改。

可以把它理解为一台去中心化的扭蛋机。创作者可以搭建自定义扭蛋机，设定奖品池、稀有度分布和定价策略。玩家转动即可立即看到结果，大奖还会触发烟花特效。整个盲盒经济完全透明——概率、库存、支出全部记录在链上，任何人都可以验证。

GASBOX 最大的亮点在于机器本身的透明度。奖品表、库存和配置都写在链上，玩家可以清楚看到自己面对的概率结构。Keeper 自动化则会在大奖产生时全平台广播，制造社交话题和热度。

## 玩法说明

1. **浏览机器** — 探索各种主题扭蛋机，每台机器有不同的奖品、稀有度和抽取费用。
2. **登录并抽取** — 用社交账号或钱包登录，支付抽取费用（最低 0.1 GAS）即可开抽。
3. **查看奖品** — VRF 在链上生成随机种子，奖品瞬间揭晓，配合精美的揭示动画。
4. **领取奖励** — NEO、GAS、NFT 或积分自动到账。
5. **再来一次** — 想继续就再开一抽，继续追那个传说级掉落吧！

## 核心特性

- **可验证公平**：每次抽取使用链上 VRF（可验证随机函数），种子公开、算法确定——任何人都可以验证结果。
- **多层稀有度**：奖品横跨多个稀有度等级，抽取前可查看精确概率和剩余库存。
- **超低门槛**：最低 0.1 GAS 即可参与。
- **创作者机器**：任何人都可以创建扭蛋机，自定义奖品、概率和定价。
- **大奖广播**：Keeper 自动检测高价值中奖，全平台推送庆祝通知。
- **机器交易**：扭蛋机可以挂牌出售——买入一台盈利中的机器，成为运营者。

## 技术架构

### 智能合约

| 组件         | 详情                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| **合约名称** | `MiniAppGASBox`                                                      |
| **开发语言** | C#（Neo N3 智能合约）                                                  |
| **区块链**   | Neo N3                                                                 |
| **抽奖流程** | `initiatePlay` → VRF 种子生成 → 客户端模拟选择 → `settlePlay` 链上验证 |
| **资产类型** | 同质化代币（NEO/GAS，类型 1）和 NFT（类型 2）                          |

### 服务层技术

- **VRF（可验证随机函数）**：链上随机数确保每次抽取公平。种子在 `initiatePlay` 时生成，用确定性算法选择奖品。
- **Keeper（自动化）**：监听大奖事件（高价值 `PlayResolved`），触发全平台广播通知和庆祝效果。
- **当前钱包流程**：当前测试网版本仍采用直接钱包交易，而不是 AA Session Key。

### 合约接口

| 方法                | 类型 | 参数                                | 说明                             |
| ------------------- | ---- | ----------------------------------- | -------------------------------- |
| `initiatePlay`      | 操作 | `player`, `machineId`               | 用户先向合约预付 GAS，再发起抽奖并生成 VRF 种子 |
| `settlePlay`        | 操作 | `player`, `playId`, `selectedIndex` | 结算抽奖——验证选择并分发奖品     |
| `buyMachine`        | 操作 | `player`, `machineId`               | 使用直接预付 GAS 购买挂牌出售的扭蛋机 |
| `getMachineDetails` | 查询 | `machineId`                         | 获取机器信息（奖品、价格、库存） |
