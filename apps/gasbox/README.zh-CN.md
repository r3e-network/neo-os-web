# GasBox 链上扭蛋机

GasBox 是围绕 `MiniAppGasBoxV2` 设计的 Neo N3 扭蛋小游戏。正式前端当前处于“浏览与恢复”模式：固定区块信标版合约完成部署前，新的抽取、机台发布、奖池补充和激活操作全部禁用。

原因是已确认的部署不一致：本地替换源码/构建使用固定的 `commitIndex + 1` 区块哈希，但主网和测试网 manifest 仍绑定到一个没有 `update` 方法的旧版实时 ABI。其部署 manifest 标明使用结算区块的 `Runtime.GetRandom`，仓库中与该 ABI 对应的版本会在稍后的结算重试中重新抽取。这不是前端承诺的游戏逻辑，因此不能继续接受新的付费写操作。

## 当前可用

1. 无需连接钱包即可读取实时机台目录。
2. 查看抽取价格、加权概率、总奖池、已预留奖池和空闲奖池。
3. 恢复并揭晓门禁启用前已经提交的抽取。
4. 通过 `withdraw(account)` 提回未使用的预付 GAS。
5. 提取创作者收益或未预留奖池；已预留资金保持不动。

## 兼容部署后启用

1. 连接 Neo N3 钱包并提交 GAS 下注；已有预付余额会优先复用。
2. 固定的下一区块信标生成后揭晓；结算无需许可，并且只支付一次。
3. 页面刷新后，按“网络 + 合约 + 钱包”保存的记录会恢复“揭晓”，不会重复下注。

## 创作者流程

- `createMachine` 创建以 GAS 定价、以 NEO 或 GAS 为奖品资产的机台。
- `addItem` 写入从 1 开始编号的加权奖品。
- 使用带机台 memo 的 NEP-17 转账为奖池注资。
- 只有空闲奖池足以覆盖最大奖品时，`setActive` 才能启用机台。
- `withdrawRevenue` 提取累积的 GAS 收益。
- `withdrawPool` 只能提取未被待揭晓抽取预留的奖池，并可能让资金不足的机台自动停用。

所有金额判断和写操作都使用十进制字符串形式的精确基础单位；界面显示值由这些精确值派生。

## 实时合约绑定

| 网络 | 合约 |
| --- | --- |
| Neo N3 主网 | `0x30e9d4a4758827361c3b51a0e8460b067e58b1db` |
| Neo N3 测试网 | `0x30e9d4a4758827361c3b51a0e8460b067e58b1db` |

前端会检查网络、合约地址、V2 必需只读接口和部署兼容性。当前旧哈希仍可读取，但无法通过付费写入门禁。恢复条件：将固定信标版构建部署为新合约，只读核验后更新 registry 和 manifest 绑定。当前证据记录在 `NETWORK_STATUS.md`。

## 前端设计

- React + TypeScript + 共享 MiniApp framework
- 复用现有 GasBox 扭蛋机与胶囊资源
- NEO/GAS 使用共享 Neo Press Kit 官方 `CoinArt`
- 动画只由真实交易状态驱动，不使用假计时器或模拟中奖结果

## 当前范围

GasBox V2 只支付同质化的 NEO 或 GAS 奖品。目前不支持 NFT、机台交易、VRF、Keeper 自动结算或 AA Session Key。
